# Калькулятори здоров’я та комунальних платежів

## Опис

Windows Forms застосунок на C#, який містить два калькулятори: для розрахунку індексу маси тіла та вартості комунальних послуг.

## Можливості

- розрахунок ІМТ за вагою та зростом;
- визначення категорії ваги;
- розрахунок вартості води, електроенергії та газу;
- відображення витрат у таблиці;
- підрахунок загальної суми платежів.

## Запуск

1. Відкрити проєкт у **Visual Studio**.
2. Виконати збірку проєкту.
3. Запустити застосунок.

## Використання

Для ІМТ потрібно ввести вагу та зріст і натиснути **«Розрахувати ІМТ»**. Для комунальних платежів вводяться показники та тарифи, після чого натискається **«Розрахувати платежі»**.
