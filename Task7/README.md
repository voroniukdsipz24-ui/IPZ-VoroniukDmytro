# Калькулятор "Скільки коштує моя звичка"

Windows Forms програма на C#, яка показує, скільки грошей витрачається на щоденну звичку.

## Можливості

- Введення назви звички та щоденної витрати.
- Розрахунок витрат за місяць, рік та 5 років.
- Порівняння витрат із вартістю смартфона, ноутбука, відпустки або ігрової приставки.
- Перевірка введених даних.

## Технології

- C#
- Windows Forms
- .NET

## Файли

- `Program.cs` — запуск програми.
- `Form1.cs` — логіка розрахунків.
- `Form1.Designer.cs` — інтерфейс програми.
