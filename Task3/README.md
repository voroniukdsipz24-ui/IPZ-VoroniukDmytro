# Реєстрація студента

Проста Windows Forms програма на C# для реєстрації даних студента.

## Можливості

- Введення ПІБ через `TextBox`
- Вибір дати народження через `DateTimePicker`
- Вибір групи/спеціальності через `ComboBox`
- Вибір статі через `RadioButton`
- Підтвердження згоди на обробку персональних даних через `CheckBox`
- Перевірка заповнення обов'язкових полів
- Виведення результату реєстрації у `MessageBox`

## Технології

- C#
- Windows Forms
- .NET Framework

## Запуск

Відкрити проєкт у Visual Studio та запустити його за допомогою `F5`.

Після запуску користувач заповнює форму та натискає кнопку **«Зареєструвати»**.
