# Трекер особистих фінансів

WinForms-додаток на C# для обліку особистих доходів і витрат у різних валютах.

## Можливості

- Додавання доходів та витрат.
- Вибір категорії та валюти.
- Перегляд операцій у `DataGridView`.
- Фільтрація операцій за категоріями.
- Автоматичний розрахунок балансу для UAH, USD, EUR та PLN.
- Видалення операцій.
- Збереження та завантаження даних із файлу.

## Технології

- C#
- Windows Forms
- .NET
- DataGridView
- List
- Файлове збереження
