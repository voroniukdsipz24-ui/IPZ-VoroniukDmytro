# Калькулятор підписок

Проста програма на **C# Windows Forms** для контролю витрат на щомісячні підписки.

## Можливості

- введення місячної зарплати;
- додавання назви та ціни підписки;
- відображення списку підписок;
- автоматичний підрахунок загальних витрат;
- розрахунок залишку зарплати;
- очищення списку та результатів.

## Файли

- `Program.cs` — запуск програми.
- `Form1.cs` — основна логіка.
- `Form1.Designer.cs` — інтерфейс форми.

## Запуск

Відкрити проєкт у **Visual Studio**, запустити через `F5` та ввести необхідні дані.
