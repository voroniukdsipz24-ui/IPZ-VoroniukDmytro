# Тестова анкета

Проста програма на **C# Windows Forms**, яка дозволяє пройти тест із декількох запитань.

## Можливості

- Вибір відповідей через `RadioButton`.
- Вибір декількох відповідей через `CheckBox`.
- Автоматичний підрахунок балів.
- Виведення результату після завершення тесту.

## Структура

```text
TestQuestionnaire
├── Program.cs
├── Form1.cs
└── Form1.Designer.cs
```

## Запуск

Відкрити проєкт у **Visual Studio**, скомпілювати та запустити програму.
