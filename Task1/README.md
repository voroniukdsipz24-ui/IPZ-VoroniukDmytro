# Калькулятор трьох чисел

## Опис
Простий Windows Forms застосунок на C#, призначений для виконання основних математичних операцій із трьома числами.

## Можливості
- введення трьох чисел;
- обчислення суми;
- обчислення різниці;
- обчислення добутку;
- відображення результатів у вікні програми.

## Запуск
1. Відкрити проєкт у **Visual Studio**.
2. Виконати збірку проєкту.
3. Запустити застосунок.

## Використання
Користувач вводить три числа у відповідні поля та натискає кнопку **«Обчислити»**. Після цього програма виводить суму, різницю та добуток введених чисел.
