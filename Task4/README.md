# Калькулятор кредиту / депозиту

Проста Windows Forms програма на C#, яка дозволяє виконувати розрахунок кредиту або депозиту.

## Можливості

- Введення суми.
- Введення річної відсоткової ставки.
- Введення терміну в місяцях.
- Вибір режиму: **кредит** або **депозит**.
- Розрахунок щомісячного платежу та відсотків.
- Виведення детального графіку в `DataGridView`.
- Перевірка правильності введених даних.

## Технології

- C#
- Windows Forms
- .NET
- DataGridView

## Файли

```text
Program.cs
Form1.cs
Form1.Designer.cs
```

## Запуск

Відкрити проєкт у Visual Studio та запустити його через `F5`.

Програма має простий графічний інтерфейс і призначена для навчального використання.
